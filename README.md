# INIB Sales Data Analysis

## Project Overview

This project analyzes Superstore sales data using Python to identify
sales trends, profitability, customer segments, product performance,
regional performance, and the impact of discounts.

## Objectives

- Analyze overall sales and profit
- Identify monthly sales trends
- Analyze category and sub-category performance
- Compare regional performance
- Analyze customer segments
- Identify top and loss-making products
- Study the relationship between discounts and profit
- Calculate overall and category-level profit margins
- Generate actionable business recommendations

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook
- Exploratory Data Analysis (EDA)
